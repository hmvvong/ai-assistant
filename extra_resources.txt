2.	Tell me about a project
(answer the EDI validation platform here)
One project I worked on was an EDI validation platform for supplier onboarding.
The project had two main parts.
The first part was converting a buyer’s spec into structured validation rules. Each buyer has a PDF specification describing what their EDI documents should look like, including required fields, hierarchy, and business rules.
I built an AI workflow that reads the specification and converts it into a structured JSON schema. The process consists of several phases and uses predefined tool calls in each phase. It first scans the document to understand the overall structure, then processes each section one by one, then extracts the business rules, and finally builds the complete JSON.
The second part was the validation engine. When a supplier uploads an EDI file, the backend automatically matches it with the buyer’s rule and validates the document against those rules.
If there are errors, you can see exactly where the document failed. There is also an AI assistant where the user can click an error and get an explanation and a suggested fix. Then they can fix the document and rerun the validation until it passes.
